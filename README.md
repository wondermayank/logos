## 📖 About

**logos** is a free, searchable library of more than **15,300 high-quality SVG logos** for developer tools, popular apps and tech brands. Use it when you need a crisp brand logo for a website, README, dashboard, portfolio or presentation.

It is built by [Mayank (Wondermayank)](https://wondermayank.in) as part of the **Thunder** family of free tools.

## ✨ Features

- 🔎 **Instant search** across 15,300+ logos (try `react`, `stripe`, `figma`)
- 🗂️ **Category filters** with logo counts, plus alphabetical sorting
- 🔷 **Type filter:** show All, Icons only, or Wordmarks only
- 🧱 **Grid and list views**, with pagination for fast browsing
- 📋 **Copy menu:** copy a logo in different formats, including React code
- ⬇️ **One-click SVG download**
- 🖼️ **SVG Viewer:** a page to preview SVG files
- ✏️ **SVG Maker:** a page to create and edit SVGs
- 🌗 **Light and dark mode** (remembers your choice)
- 📱 Responsive layout
- 🆓 Free, no signup

## 🚀 Getting started

### Use online

Open **https://project.wondermayank.in/code/svg/**, search for a brand, hover over a logo and choose **copy** or **download**.

### Run locally

No framework is needed. It is a static site.

```bash
# 1. Clone the repository
git clone https://github.com/wondermayank/logos.git

# 2. Go into the folder
cd logos

# 3. Serve it with any static server
python -m http.server 8000
```

Then open `http://localhost:8000`.
